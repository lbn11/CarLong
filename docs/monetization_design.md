# 变现结构

> 状态（2026-10-26）：**纯广告变现，无内购**。
> 激励视频走 AdMob 单渠道（5 个广告位），商店里那个「¥6 购买 600 🪙」的模拟内购已删除。
> 落地细节见 `docs/admob_setup_guide.md` 与 `docs/ad_integration_plan.md`。

## 1. 唯一的收入来源：激励视频

### 五个广告位

| 广告位 | 存档 key | 入口 | 单点上限 | 冷却 | 奖励 |
|---|---|---|---|---|---|
| `shopDaily` | `shop` | 商店「每日福利」 | **3 次/日**（`GameConfig.dailyAdLimit`） | 8s | +100 🪙 |
| `mergeRevive` | `revive` | 合成失败续命 | 每局一次（`MergeGame.revivesLeft`） | 3s | 继续本局 |
| `mergeDouble` | `double` | 合成胜利金币 ×2 | 每局一次 | 3s | 金币翻倍 |
| `parkingUndo` | `undo` | 停车撤销卡不足时回退 3 步 | **10 次/日** | 12s | 回退 3 步 |
| `parkingHint` | `hint` | 停车「下一步最优走法」 | **10 次/日** | 12s | 提示一步 |

全局硬上限 **30 条/日**（`AdPolicy`），可用 `--dart-define=AD_GLOBAL_DAILY_CAP=20`
与 `ADS_DISABLED=true` 在不发版的情况下调低或全关（审核期间停广告专用）。

### 三道闸（顺序固定）

```
总开关 → 全局总量 → 单点上限 → 冷却
```

玩家看到的是**最顶层**的原因。`capped` / `cooldown` 在本地就拦掉，不烧 SDK 请求。
发奖判据只有 `AdOutcome.rewarded`；`skipped / failed / unavailable` 一律不发。
`skipped` 也写 `_lastShownAt` —— 否则「秒关再点」会被渠道判为无效流量。

### 经济红线

- **商店 3 次 × 100 = 300 🪙/日 已是最大固定产出，不要再加。**
- 宝箱（150 🪙 抽一次）是**回收阀**：期望收益约 -20%，金币不会净增。
- 停车 3 星免费发 booster，与商店完全解耦 —— 商店不是 booster 直购点。

### 合规要点

- 广告只在玩家主动点击后展示，不做强制插屏（当前无插屏位）。
- 未成年人 / 家长控制下 `AdService` 直接返回 `unavailable`，不请求广告。
- 同意顺序 **UMP → ATT**，`canRequestAds() == false` 时一个请求都不发。
- 激励文案用「看广告领取」，不用「看完必得大奖」这类诱导表述。

## 2. 为什么不做内购（以及删掉了什么）

### 已删除的东西（2026-10-26）

| 位置 | 内容 |
|---|---|
| `lib/screens/shop_screen.dart` | 「内购礼包 · 600 🪙 / **¥6 购买**」按钮 + `_buyCoinPack()` |
| `lib/game/game_config.dart` | `coinPackAmount`（600） |
| `test/ui_interactions_test.dart` | 原「购买后金币增加」测试 → 改为**反向回归锁**（商店不许出现 `¥` / 「购买」） |
| `site/support.html` | 「内购与退款」→ 「游戏里有内购吗」（明确回答没有） |

`AnalyticsService.iapPurchase` 保留（事件名是资产），但**当前无调用点**。

### 三条删除理由

**① 审核红线。** 界面上标了真实价格却不扣款、点击直接到账，等于把一个未实现的付费功能
展示给审核员：

- Apple **3.1.1**：App 内解锁功能必须通过 IAP；
- Apple **2.3.1**：禁止虚假/未实现的功能；
- Google Play **Payments Policy**：真实货币定价的购买入口必须走 Play Billing。

更糟的是那个弹窗写着「演示版直接发放。上架后接入真实内购（iOS IAP / 安卓 Google Play）。」
—— 这是给开发自己看的备忘，会原样展示给审核员。

**② 只发海外，却硬编码人民币。** 那个按钮写死了 `¥6`。海外双端发行时出现人民币符号：
玩家看不懂、地区定价与税对不上、审核会追问。**IAP 的价格必须由商店返回**
（`ProductDetails.price` 已按地区本地化），代码里永远不能写死金额。

**③ 它把「一次广告值多少钱」算给玩家看。** 这个按钮和「看广告 +100」并排放在同一张
卡片里，形成直接对比：

```
看广告 30 秒  →  +100 🪙
花 ¥6        →  +600 🪙
```

玩家一秒就能算出「30 秒 = ¥1」。而实际折算：激励视频 eCPM 按 $10–15 估，单次完整观看
约 **¥0.07–0.1**。等于自己向玩家报了 10 倍以上的虚价 —— 理性玩家不买，愿意买的人
算完觉得被宰。广告游戏最不该让玩家做的就是这个换算。

### 卖金币为什么是最差的内购形态

金币在本作里**有免费硬产出**（300 🪙/日），所以「卖金币」本质是卖「免看广告」。
600 🪙 = 6 次广告 = 2 天的额度。单看单笔交易：你损失约 ¥0.5 的广告收入、收到 ¥6，
是赚的；但它长期做坏了两件事 —— 向玩家锚定「一次广告 ¥1」，以及让付费玩家彻底
退出广告池。**要卖「免看广告」，就直接卖「去广告」，不要绕道金币。**

### 如果以后要做内购，做什么

| 形态 | 定价参考 | 为什么 | 代价 |
|---|---|---|---|
| **去广告买断**（Remove Ads） | $2.99–4.99 | 把「从不看广告」的那 20–30% 高价值用户变现，且不伤害广告盘 | `in_app_purchase` + 双端商品配置 + 首次提审必须一起提交 |
| 双倍 / 月卡订阅 | $1.99/月 | ARPU 稳定，可预期 | 续订、退款、税务复杂，个人开发者不建议先做 |
| 卖金币 / 卖 booster | ❌ | 见上 | — |

**前置条件：先拿到 AdMob 的 eCPM 与填充基线。** 没有基线就定内购价格 = 盲拍。

**做「去广告」的实现注意**：付费后激励视频不是「消失」，而是「点击直接领取」。
关卡难度与 booster 供给都是按「看广告可补」设计的，直接删掉广告入口会同时破坏
经济循环与卡点体验。

## 3. 留存钩子（已落地）

| 机制 | 形态 | 存档字段 |
|---|---|---|
| 离线收益 | 离开 30min+ 回来自动领（12 🪙/h，上限 8h） | `lastSeenAt` |
| 收藏召回 | 首页图鉴进度 X/50 + 还差 N 个 + 全图鉴大奖 | `collectionRewardClaimed` |
| 每日挑战 | 每天一关（+150 🪙） | `dailyClearedDate` |
| 签到 | 7 日循环（10–80 🪙） | `signIn*` |

## 4. 埋点

| 事件 | 何时记 | 用途 |
|---|---|---|
| `ad_impression` | 每次**请求**广告（含失败） | 算漏斗：请求 → 有填充 → 看完 |
| `ad_watch` | 发奖成功 | 算钱 |
| `iap_purchase` | **预留，当前无调用点** | 接入 IAP 后必须在**发货成功后**调用，不要在点击时调用 |
| `chest_open` / `sign_in` / `daily_clear` | 对应行为 | 经济与留存 |

只记 `ad_watch` 会把「没填充」误判成「玩家不想看」，两个事件都要。
