# 变现设计方案（任务 1 变现部分）

> 状态：**模拟实现已落地**（商店"每日福利"激励广告 + "金币礼包"），真实 SDK/IAP 接入需上架前完成。
> 本文档说明接入清单与合规要点。

## 1. 激励视频广告（Rewarded Video）

### 产品形态
- 入口：商店「每日福利 · 看广告赚金币」
- 频率：每日 3 次（`PlayerData.adWatchDate / adWatchCount` 跨日重置）
- 奖励：每次 +150 🪙（模拟版点击即发）
- 定位：纯增益变现，不阻断玩法（看或不看都不损失）

### 接入清单（上架前）
| 项 | 说明 |
|---|---|
| 广告 SDK | 建议穿山甲（国内）/ AdMob（海外）二选一或聚合（GroMore/MAX） |
| 广告位 | 激励视频 1 个，reload 策略（预加载下一条） |
| 回调 | `onRewardedComplete` 后才发奖（防作弊）；服务端/本地二次校验次数 |
| 配置 | 后端下发开关 + 每日上限，A/B 测试奖励倍数 |

### 合规要点
- 广告标识清晰（不伪装成 UI 按钮之外的交互）
- 未成年人保护：青少年模式不展示广告或改为无广告奖励直发
- 用户主动触发才展示（不可强制弹出）

## 2. 金币礼包（IAP 内购）

### 产品形态
- 入口：商店「金币礼包」600 🪙（¥6 档）
- 模拟版：点击直接 +600（演示）
- 真实版：走平台 IAP 扣款后发货

### 接入清单（上架前）
| 项 | 说明 |
|---|---|
| iOS | StoreKit 2，App Store Connect 配置商品 + 沙盒测试 |
| Android | Google Play Billing（海外）/ 应用商店 SDK（国内各渠道） |
| 发货 | 服务端订单校验（receipt/签名）后发放，防篡改 |
| 首充 | 建议做首充双倍（首次购买 1200 🪙）提升转化 |

### 合规要点
- 价格显示与平台一致；未成年付费需家长授权（应用商店统一处理）
- 虚拟货币不可逆向兑换现金；明示"金币仅用于游戏内消费"

## 3. 留存钩子（任务 1 留存部分，已随本轮落地）
| 机制 | 形态 | 存档 |
|---|---|---|
| 离线收益 | 离开 30min+ 回来自动领（20🪙/h，上限 8h） | `lastSeenAt` |
| 收藏召回 | 首页图鉴进度 X/17 + 还差 N 个 + 全图鉴大奖 500🪙 | `collectionRewardClaimed` |
| 每日挑战 | 已有（+150） | `dailyClearedDate` |
| 签到 | 已有（7 日 10-80） | `signIn*` |

## 4. 建议的接入顺序（上架前）
1. 接入激励视频 SDK（穿山甲/AdMob），替换商店模拟按钮
2. 配置后端广告开关 + 每日上限
3. IAP 商品上架（iOS Connect / 渠道后台），替换金币礼包模拟
4. 全链路沙盒/审核测试（广告发奖、IAP 发货、未成年模式）
5. 埋点补齐：`ad_watch` / `iap_purchase` / `offline_reward` 事件（现有 AnalyticsService 扩展）
