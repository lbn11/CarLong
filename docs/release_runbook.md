# 上架操作手册：一步一步照做

只列**还没做**的动作，按顺序执行。细节要查时再去翻
`admob_setup_guide.md`（广告）和 `store_launch_overseas.md`（商店）。

**当前路线：先上 iOS（App Store），Google Play 后置。**

先上 iOS 是对的，而且更快：iOS **没有** Play 那种「20 人封闭测试满 14 天」的强制等待，
包过审就能发。代价是 Apple Developer Program 年费 **¥688/年**（人民币计），
这笔钱在注册当时就要付，是唯一不可后补的支出。

Google Play 放在第 9 步（可选、随时可补），它那 14 天封测不阻塞 iOS 任何一步。

---

## 关于「收款卡能不能以后再补」——分两笔钱，别混为一谈

| | 谁给谁 | 什么时候付/收 | 能不能后补 |
|---|---|---|---|
| **A. Apple 年费 ¥688** | 你 → 苹果 | **注册当时** | ❌ 不能。不交就进不了 App Store Connect，后面全部免谈 |
| **B. AdMob 广告收入** | 谷歌 → 你 | 有收入之后 | ✅ 大部分能后补，**但有一件必须现在做**，见下 |

**B 这条线的完整时序**（Google 官方口径）：

1. 收入累计到 **$10** → 后台才允许你选收款方式（**所以现在想加银行卡也加不了**）
2. **身份验证** → 触发后 45 天内上传身份证，时间充裕
3. **地址 PIN 验证** → 谷歌向你的收款地址**平邮一张实体卡**，中国 2–4 周，
   收到后在后台输入 PIN，4 个月内必须完成
4. 余额 ≥ **$100** → 每月 21 号左右打款（电汇约 3–10 个工作日到账）

⚠️ **唯一的坑：PIN 没验证，不只是收不到钱，而是「广告会被暂停展示」。**
PIN 卡走国际平邮、无追踪、中国成功率不高，只有 4 次申请机会，
第 4 次还收不到要走人工验证（上传身份证，地址须与账户一致）。
所以这不是"等有钱再说"的事——**地址现在就要填对**。

**现在就该做的 2 分钟（第 4 步会再提醒一次）**：
进 AdMob → 收款 → 核对收款人姓名（与身份证/银行卡一致）与地址，
地址里**加上手机号**（平邮本身不含电话，写了快递员才联系得到你），
邮编到 postal 官网查准。

## 动手前先查：AdMob 到底"通过"了没（5 分钟，不查可能白干）

**"通过"在 AdMob 里是三层意思，三层都过了才算真通过：**

| 层 | 在哪看 | 判据 |
|---|---|---|
| ① **账号批准** | 登录后**顶部横幅**有无警告；收注册邮箱有没有拒信 | 无警告横幅 = 已批准。新账号约 24 小时，极少数长达 2 周 |
| ② **付款资料已验证** | 侧栏「付款」→ 页面顶部提示 | **这一步没做完，应用会永远卡在「正在准备」** |
| ③ **应用可投放** | 侧栏「应用」→ 查看所有应用 → 状态列 | 见下表 |

**应用状态对照**（Google 官方口径）：

| 状态 | 含义 | 你要做什么 |
|---|---|---|
| **正在准备** Getting ready | 审查中，通常 2–3 天 | 什么都不做。**若你是刚注册 AdMob，这个状态会一直卡着，直到账号验证通过（即 ②）** |
| **需要审查** Requires review | 还没提交审查 | 把应用**链接到 App Store**（应用设置里），链接后自动开始审查 |
| **需要注意** Needs attention | 有问题要修 | 进「政策中心」→ 被拒的应用，看具体原因 |
| **可投放**（无标记） | 已获准 | ✅ 齐了 |

⚠️ **两个会让你白慌半天的坑：**

1. **应用必须已经上架、且在 AdMob 里链接了商店，审查才会启动。**
   也就是说——**iOS 上架后的头 2–3 天，广告投放量是受限的**，这是正常的排队审查，
   不是配置错误。**这期间不要申诉、不要删改广告单元、不要重新提交**，
   什么都做不了也没必要做，等就是了。别把"第一天零收入"当成事故。
2. **app-ads.txt 要 AdMob 爬取验证（约 24 小时）**，而它生效的前提是：
   应用已注册到 App Store + 商店 listing 里填了开发者网站。
   我们网站已上线（`carlong.pages.dev`）、文件已在根目录，
   **上架后记得回 AdMob 补「应用商店」链接字段**，否则这 24 小时又要重数。

> 关于收款的精确说法（修正）：**「付款资料」和「收款方式」是两件事，别混。**
> 付款资料 = 收款人姓名 + 地址，**它是账号验证的前提，必须早就有**（②）；
> 收款方式 = 电汇银行账户，**要收入到 $10 才允许添加**，现在加不了是正常的。

## 第 0 步：先定发行主体（中国身份可以直接发全球，**不用注册美国账号**）

**结论：就按中国大陆身份注册，不要去搞美国账号。**

官方依据（2026-10 查证）：

- **Apple**：官方中文帮助明确写了「中国大陆地区的开发者可以使用 Apple Developer App
  注册 Apple Developer Program」（个人 / 一人公司），需身份证 + 自拍照 + 双重认证，
  年费按人民币计（¥688/年）。**Apple Developer Program 的会员资格本身支持面向全球
  用户分发**，在 App Store Connect 里勾目标国家即可。
- **Google Play**：官方「支持开发者和商家注册的地区」列表里 **China 两项都是 ✔**
  （开发者注册 ✔、商家注册 ✔，默认币种美元）—— 也就是中国主体能注册、也能收款。

**为什么不要注册美国账号**（反而更麻烦）：

| 坑 | 说明 |
|---|---|
| 身份验证过不了 | 美区 KYC 只认美国签发的证件（驾照 / 州 ID / 绿卡 / 美国护照）。中国护照 + 美国地址会被直接判不合规 |
| 借别人身份风险大 | 用亲友/合伙人身份代验证，账号归属有纠纷风险，出事无法申诉 |
| 地区不可改 | Google 明确：账号国家/地区一经确认不能改。想换只能注销重开，应用全部下架 |
| 信息自相矛盾 | 注册地区要和证件、地址、税务、银行资料一致，造假是封号级问题 |

**中国身份真实的限制（都是钱和访问的问题，不影响发全球）**：

1. **付款**：要有能付美元的 Visa / Mastercard（银联单标卡大概率扣不上）。
   苹果这边友好些——中国区可以用人民币订阅扣款。
2. **收款**：AdMob / App Store 收入打回国内，走 Payoneer 或电汇最稳。
   纯电汇到国内银行，入账时可能被银行问询资金来源。
3. **访问后台**：Play Console 在中国大陆需要自己解决网络，不影响上架本身。
4. **税务**：美国侧走 W-8BEN（非美国主体），本项目已提交、待审核；
   审核通过后预扣税率会从 30% 占位降到中美协定税率。中国侧的境外收入自行申报。

⚠️ **一个容易踩的坑**：游戏在中国大陆 App Store 上架需要**版号**。
本项目只发海外 → **在 App Store Connect 的「App 可用性」里不要勾中国大陆**，
直接绕开版号问题。

## 第 1 步：Apple Developer Program（先上 iOS = 这一步是唯一前置）

**换链接、传包、填问卷，全都在商店后台里做——而进后台的前提是账号 + 已建好的
「应用条目」。所以这一步才是真正的起点，不是"5 分钟收尾"。**

| 账号 | 费用 | 当前路线 |
|---|---|---|
| **Apple Developer Program** | **¥688/年**（人民币） | **现在就要办**，个人/一人公司即可 |
| Google Play 开发者 | $25 一次性 | 个人号已注册，放到第 9 步 |

注册：<https://developer.apple.com/programs/>（或用 iPhone 上的
**Apple Developer** App 走大陆通道，身份证 + 自拍照 + 双重认证）。
个人号会显示你的真实姓名；公司号要 D-U-N-S（免费但 1-2 周），先上 iOS 就别走公司号。

- [ ] 年费已付、会员资格生效（进 <https://appstoreconnect.apple.com> 看得到界面）
- [ ] 在 Certificates, Identifiers & Profiles 里注册 Bundle ID：
      **`com.carlong.mergefleet`**（与工程一致，别打错）

> 支付方式：中国区可以用人民币结算，银联 / Visa / Mastercard 一般都能过。
> 这笔是**唯一不能后补**的钱——它买的是"进后台的资格"，跟广告收入无关。

- [ ] **App Store Connect** → 我的 App → 左上角 `+` → 新建 App

- [ ] 建完立刻做一件小事：**「App 信息」→ App 可用性 → 不要勾中国大陆**
      （游戏在大陆要版号，我们只发海外，直接绕开）

> 建条目本身不需要安装包，随时可以建。**建完才能填隐私政策链接。**
> Play 的条目放到第 9 步再建。

## 第 4 步：真机广告验证（必须在换正式包之前做）

**红线：绝不能拿自己的正式广告位在自己手机上反复点。** 那是无效流量，
AdMob 第一次警告、第二次直接停号。正确做法是把调试机加进测试设备列表。

1. **iPhone 真机**连电脑（先上 iOS，就用真机，模拟器不能代表 ATT 行为），跑：

   ```bash
   flutter run --dart-define-from-file=ads.env.json
   ```

   首次会弹 ATT 跟踪授权框——这就是 iOS 上必须真机验证的原因。

2. 日志里搜 `setTestDeviceIds`，拿到你设备的哈希
   （iOS 是 **40 位十六进制**；Android 形如 `3F2A5C9D...`）

3. 写进 `ads.env.json`（**这个文件不入库，别提交**）：

   ```
   "ADMOB_TEST_DEVICE_IDS": "3F2A5C9D..., 另一台设备"
   ```

   多台设备英文逗号分隔。

4. 重新构建。之后你手机请求到的都是测试广告：
   **右上角必须有「Test Ad」角标**——看不到说明没识别成功，别继续点。

5. 五个广告位各走一遍，判据三条同时成立：
   出现 `Reward granted` → 金币到账 → 该点位当日剩余次数 -1

   - [ ] 商店 +100 金币
   - [ ] 停车/合成 复活
   - [ ] 双倍奖励
   - [ ] 撤销
   - [ ] 提示

6. 再走四条失败路径：**中途关闭**（不发奖）、**飞行模式**（无填充，不崩）、
   **当日上限**（拦住并给提示）、**冷却中**（12 秒内重复点被拦）

7. **iOS 专属两条**（苹果审核会自己跑一遍，先自查）：
   - [ ] 首次启动的 ATT 弹窗出现在**广告请求之前**（顺序反了 = EEA 未同意就索取跟踪权限）
   - [ ] 设置页「隐私设置与广告偏好」入口能打开 UMP 表单并改同意状态

详细坑位见 `admob_setup_guide.md` §4。

## 第 5 步：UMP 三条消息发布（不发 = 欧盟永远不弹窗）

AdMob 后台 → **Privacy & messaging** → 建三条并逐个 **Publish**：

| 消息 | 覆盖 | 要点 |
|---|---|---|
| GDPR | 欧盟/英国/瑞士 | 必须有「Consent」和「Do not consent」两个选项；隐私政策 URL 填上面的地址 |
| US states | 加州等 | CCPA，提供「Do not sell/share」入口 |
| IDFA explainer | iOS 全局 | iOS 上先解释再弹 ATT，通过率更高 |

**Draft 不算数，必须 Publish。** 没发布时代码不会报错，只是欧盟用户永远看不到表单——
属于「代码没问题、合规不合格」。

## 第 7 步：iOS 传包提审（当前主战场）

1. 构建：

   ```bash
   flutter build ipa --release --dart-define-from-file=ads.env.json
   ```

2. 上传：Xcode → Open & Distribute 的 Transporter，或命令行

   ```bash
   xcrun altool --upload-app -f build/ios/ipa/*.ipa -t ios --apiKey <KEY> --apiIssuer <ISSUER>
   ```

3. 填 **App Privacy** 问卷（口径：广告 ID、无账号体系、进度仅本地）
4. **年龄分级问卷**：按「非儿童应用」申报（别勾儿童，否则个性化广告违规）
5. 提交审核

⚠️ App Privacy 里声明的内容必须和网站隐私政策**一字一句对得上**，
对不上就是「声明与实际不一致」的下架级问题。

## 第 8 步：AdMob 收款前置（2 分钟，现在就做，别等有钱）

收入到 $10 之前后台不给选收款方式，所以银行卡**加不了也不用加**。
但下面这两件事必须现在做，否则会反噬到广告展示本身：

- [ ] **收款人姓名** 与身份证、未来银行卡户名完全一致
      （不一致 → 电汇退回 + 身份验证失败）
- [ ] **收款地址** 是你能真的收到国际平邮的地址，且**在地址行里写手机号**
      （PIN 卡走平邮、无追踪、不含电话，写了手机号派件员才联系得到你）
- [ ] 邮编到 postal 官网核实，别凭记忆填

> 顺序上它在第 8 步，是因为包上传后很快就会跑到 $10 —— 别到时候才手忙脚乱。

## 第 9 步：Google Play（后置、可选；要数 14 天）

4. 内容分级问卷

6. 14 天后申请正式发布

## 不用等的事

W-8BEN 税表**已提交，等身份证审核**，不阻塞上面任何一步。它只影响预扣税率
（审核期按 30% 占位，批准后降到中美协定税率）。审核期间广告照常展示、照常计费，
所以不用等它。唯一要避开的还是那句：**别拿正式 unit 自己点广告**。

应用上架后回 AdMob 把商店链接补进应用详情的「应用商店」字段，否则广告可能被限流。
