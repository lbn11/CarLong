# 车水马龙 (Merge Fleet)

合成玩法（三消升级）的交通主题手机/桌面小游戏，基于 Flutter + Flame。

## 玩法

- **合成**：把同等级车辆卡片合并，3 张升 1 级，一路合成到最高级「彗星」。
- **17 档车辆 × 5 大车系**：陆地 / 重工 / 轨道 / 航空 / 星际。
- **四种障碍**：冰块（四邻合成消层）、锁链（锤子清除）、石块（永久占格）、传送门（成对传送）。
- **四张特殊卡**：万能卡（与任意卡合并）、炸弹卡（集 3 引爆清 3×3）、迷雾格（落子揭开）。
- **两种目标**：合成指定车辆 / 清空棋盘，可叠加限时或限步。
- **主线 70 关** + **无尽模式**（目标逐级提升，死局即止） + **每日挑战**。

## 系统

- 图鉴：首次合成某等级车辆点亮，按车系分组展示。
- 7 日签到：固定档位奖励，第 7 天大奖金币，断签重置。
- 无尽里程碑：每 5 档目标发奖励。
- 金币 / 道具（锤子、撤销、加牌）/ 存档（shared_preferences）。

## 运行

本机（mobian aarch64 + Linux 桌面）直接跑：

```bash
./tool/run_linux.sh
```

> 桌面真音效依赖 gstreamer：构建前需要 `libgstreamer1.0-dev` + `liborc-0.4-dev`，
> 并把 `libgstreamer-plugins-base1.0-dev` 解压到 `~/gstapp-dev`（见 `tool/run_linux.sh`，
> 因本机 mesa 被 apt hold 无法整包装 dev 包）。
